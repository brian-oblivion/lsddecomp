## Proposed learning

This unit is the head of the (former) 415-function `class_39e08` segment,
and the alpha-round lever applies directly: **before writing any C in a
class-framework unit, find the 4-instruction `lui/addiu %hi+%lo` + `jr $ra`
"return &D_xxxxxxxx" getter and run `tools/classtable.py` on its target
before touching anything else.** Here that single lookup (on
`func_8004A060`, 4 instructions) turned roughly a third of this unit's
`INCLUDE_ASM` entries into recognizable vtable slots of two related
classes, and grepping the unit's own data file for the *other* orphaned
functions' addresses found the second (sibling) class table for free.
