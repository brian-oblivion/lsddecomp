`sb`/`sw` store width. That is why it is typed `s32` here rather than
`u8`: a narrower parameter type would trigger the (absent) prologue
truncation and cost a word.

### Proposed learning

**A "write field, then re-read the same field to return it" setter
shape reloads the base pointer a second time in retail** -- write the
store and the return as two separate statements against the indexed
expression, not `return field = value;`, to reproduce the second
`lui`/`lw` of the global.
