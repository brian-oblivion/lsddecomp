# func_8004B32C

**Unit:** class_3ac78 · **Size:** 6 instructions · **Status:** MATCHED (6/6 words)

## What it does

Stores `arg1` whole into one field, and two right-shifted, truncated-to-
`s16` copies of it into two others.

## The C

```c
void func_8004B32C(Class866E8 *self, s32 arg1)
{
	self->unk74 = arg1;
	self->unk7A = (s16)(arg1 >> 11);
	self->unk78 = (s16)(arg1 >> 12);
}
```

Note the field WRITE order in source matches retail's instruction order
exactly (`unk74`, then `unk7A` computed from `>>11`, then `unk78` computed
from `>>12`) even though `unk78` sits at the lower address of the two --
this is not alphabetical or address order, it's the order the two `sra`s
appear in the disassembly, and writing it any other way risks a spurious
register-identity mismatch.
