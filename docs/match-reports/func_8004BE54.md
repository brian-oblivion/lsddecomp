## What's established (from reading the disassembly, not from a build)

**`self` (`$a0`) is never read.** No instruction anywhere in this function
dereferences `$a0` or copies it to a saved register. If re-derived, the
first parameter can be declared and left genuinely unused (see this
project's own learning: "An unused parameter in the callee shows up in the
caller as a genuinely uninitialised local" -- the callER's own `$a0` at
this call site is worth checking once this function's slot is known).
