# func_8005A1B0

**Unit:** DreamSys · **Size:** 15 instructions · **Status:** MATCHED (15/15 words)

## What it does

Vtable slot `+0x18C` (fourth of the five-function run; see
`func_8005A168.md`). Four independent bounds-checked setters in a row: each
of `unk_0x124`, `unk_0x128`, `unk_0x12C`, `unk_0x130` is overwritten with
the corresponding argument only when that argument is `>= 0`. The fourth
argument (`d`) arrives on the stack at `0x10($sp)`, the standard o32 slot
for a 5th integer argument (`this` + 4 explicit args already fill
`$a0`-`$a3`).

## The C

```c
void func_8005A1B0(DreamSys *this, s32 a, s32 b, s32 c, s32 d)
{
	if (a >= 0)
		this->unk_0x124 = a;
	if (b >= 0)
		this->unk_0x128 = b;
	if (c >= 0)
		this->unk_0x12C = c;
	if (d >= 0)
		this->unk_0x130 = d;
}
```

## Note: `unk_0x124` already had a documented meaning; this doesn't override it

An earlier round named `unk_0x124` "Result of DreamSys__UpdateTickState's (dreamTimer %
unk_0x120 == 0) check." This function ALSO writes it directly, from a
caller-supplied argument. Both are true -- multiple writers to the same
field is normal; left the earlier comment in place and added a note
cross-referencing this round.

## New fields: `unk_0x128` / `unk_0x12C` / `unk_0x130`

Split out of `unknown_values_0x128[12]` (three consecutive words,
immediately before `dreamTimeLimit`).
