### Proposed learning

A framed wrapper (allocates/frees a stack frame, saves/restores `$ra`) that
calls one function and never touches `$v0` afterward is NOT evidence of a
sibling/tail call — GCC 2.6.3 on this target does not appear to do
sibling-call elimination; it always pays for the frame. Read it as
`return callee(fwd-args);` with the callee's own return type, derived from
whether the callee itself sets `$v0` on its own return paths.
