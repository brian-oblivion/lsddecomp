### Proposed learning

**Two residues in the same function can be entangled such that the
correct fix for one only appears once the other is ALSO changed** --
here, `i + self->unkAB` was the objectively WORSE pre-loop form in
isolation (attempt 1, 34/40) but became the RIGHT one once the in-loop
recompute was split into named temps (attempt 4, 38/40). This is the
same family as the project's existing "entangled residues" note
(`func_8004B700`, where an isolated worse-scoring change was the key
unlock in combination) but for a smaller, more mechanical pair of
register-order questions rather than a branch-polarity/scheduling
pair — worth broadening that existing entry's scope.
