## What it does

An inline type check: reads the LOW BYTE of `other`'s own vtable's header
word (a `lbu`, not a masked word load) and, if it equals `0x34`, dispatches
`self->methods->slotD0(self, other)`.

## How the byte-vs-word read was derived

Retail is `lbu $v1, 0x0($v0)` where `$v0` is `other->methods`, not a `lw`
followed by a mask. `0x34` matches the LOW byte of `D_800878D4`'s header
word (`0x00000034`) -- the shared intermediate base class this unit's own
`Class866E8`, `DreamSys`, and `Class65650` all sit under (see
`docs/research/class-framework.md` and `include/class_3ac78.h`). Declaring
`AnyObjMethods`'s first field as `u8` rather than `s32` was what produced
the `lbu` directly; a `s32 header` field with `& 0xFF` in the comparison
would have loaded a whole word first.
