### Proposed learning

**`volatile` has (at least) two independent effects that are easy to
conflate: qualifying a GLOBAL's declaration affects whether repeat
reads/writes to it can be optimized away or reordered; routing an
access through a local `volatile T *` pointer ALSO affects whether the
address computation gets FOLDED into the memory instruction's own
immediate or computed into a separate register first.** A global
already declared `volatile` does not automatically get unfolded
addressing at every access site -- if retail's disassembly shows an
unfolded `lui/addiu` + plain-offset store where a directly-qualified
global compiles to a folded one, route that SPECIFIC access through a
local pointer too, even though the qualifier looks redundant.
