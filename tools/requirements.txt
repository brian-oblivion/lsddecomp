# Python tooling for the .venv. Installed by tools/setup.sh.

# KEEP VERSIONS PINNED. A worktree symlinks this venv and a fresh clone

# start disagreeing about what the binary contains.

# splat: binary splitter/disassembler (make extract). The PyPI name is
# splat64 even though the module is `splat` and it handles psx fine.
#
# THIS SET WAS RESOLVED BY HAND AND THE PINS ARE LOAD-BEARING. splat64
# declares none of the four below as install_requires, so pip installs it
# happily and `import splat` then dies at module load on whichever one is
# missing -- spimdisasm first, then n64img (imported by the n64 image
# segtypes, which load unconditionally even for a psx target). Newer splat64
# (0.50.0) wants a spimdisasm that is not on PyPI at all. If you bump any of
# these, re-run `make extract` AND `./build-and-verify.sh`; an import that
# succeeds proves nothing about whether the split still reproduces.
